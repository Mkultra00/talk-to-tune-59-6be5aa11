# EgoVerse Diversity Auditor — Design Document

## Purpose

Turn the question "is our robot-training data diverse enough?" into a reproducible, explainable number. The app compares two dataset subsets across three independent diversity signals and produces a single Composite Diversity Index, backed by visualizations, a sanity harness, and an AI-narrated explanation.

## What the app does

1. **Dataset selection**  
   The user chooses two subsets — Slot A and Slot B — from a catalog of scored datasets. Each dataset carries metadata: episode count, hours, scene count, task count, object count, and demonstrator count.

2. **Three-signal scoring**  
   For each subset the app computes:
   - **Visual Vendi Score** — diversity of DINOv3 frame embeddings, measured with the Vendi Score (a kernel-based diversity metric). Higher = more visually distinct frames.
   - **Metadata entropy** — normalized Shannon entropy over scene, task, object, and demonstrator labels. Higher = labels are more evenly covered.
   - **Motion Vendi Score** — diversity of movement descriptors. Higher = more varied physical motion.

3. **Composite Diversity Index**  
   A weighted aggregate of the three signals, scaled to 0–100. The index lets users compare subsets with a single number while still seeing the per-axis breakdown.

4. **Visual evidence**  
   - **Per-axis bars** — normalized 0–1 comparisons for Slot A vs. Slot B.
   - **UMAP scatter plot** — 2D projection of sampled DINOv3 frame embeddings. Each dot is a sampled frame; color shows the subset. Tight clusters = similar frames; spread-out regions = more diverse visual content. The plot includes animated drift, glow effects, centroid spread rings, and a live hover readout.
   - **Metadata entropy bars** — per-field entropy comparison.
   - **Kernel stability table** — Vendi scores under different kernel bandwidths, proving the A < B ordering is not an artifact of one bandwidth choice.

5. **Sanity harness**  
   Three constructed subsets with a known diversity order are sorted by the Composite Diversity Index. A green check means the metric is internally consistent.

6. **AI narration**  
   The Lovable AI Gateway generates a short, high-energy, plain-language summary that:
   - names the datasets in Slot A and Slot B,
   - explains each metric in non-technical terms,
   - describes why the diversity delta matters for robot learning generalization.
   ElevenLabs reads the summary aloud with an expressive female voice.

## Why it matters

Robot-learning models generalize better when trained on diverse data. Without measurement, a dataset can quietly collapse onto a few dominant scenes, tasks, or demonstrators, and the model overfits to those patterns. The EgoVerse Diversity Auditor makes diversity a first-class metric, so teams can:

- compare collection strategies objectively,
- catch hidden bias or collapse before training,
- justify curation decisions with reproducible numbers,
- communicate findings to non-technical stakeholders through the AI narration.

The LLM is never used to score diversity. It only narrates the precomputed math.

## Architecture

- **Frontend:** TanStack Start (React 19 + Vite 7) with Tailwind CSS v4 and shadcn/ui components.
- **State:** React `useState` / `useMemo` for dataset selection and derived metrics.
- **Metrics engine:** `src/data/metrics.ts` — deterministic dataset catalog, Vendi-style scoring, metadata entropy, motion signatures, and PRNG-based UMAP projection for consistent SSR/hydration.
- **Server functions:** `src/lib/egoverse.functions.ts` — `generateNarrative` calls the Lovable AI Gateway directly; `speakNarrative` calls ElevenLabs TTS.
- **Visualizations:** `src/components/diversity/` — `AxisBars`, `UmapScatter`, `NarrationPanel`, `DatasetPicker`, `SanityHarness`.
- **Audio:** HTML5 `<audio>` element with direct `src` assignment and manual `load()` / `play()` handling.

## Key design decisions

- **Deterministic demo metrics.** The public demo uses precomputed, seed-based metrics so the dashboard is immediately explorable without a live Modal GPU backend.
- **SSR-safe UMAP.** Coordinates are generated by a deterministic PRNG and rounded to fixed precision to avoid React hydration mismatches.
- **Direct AI Gateway fetch.** The narrative generator uses a plain `fetch` to `https://ai.gateway.lovable.dev/v1/chat/completions` with the required headers, avoiding SDK compatibility issues.
- **No hardcoded colors.** Styling uses the project's semantic design tokens and a dark "instrument-panel" aesthetic.

## Future extensions

- Wire the metrics engine to a live Modal GPU pipeline for real embedding / Vendi computation.
- Upload custom dataset manifests and compute scores on demand.
- Export the audit report as a PDF or shareable link.
- Add more diversity signals (e.g. temporal novelty, object-interaction diversity).
